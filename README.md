# Estudos de Programação

Exercícios desenvolvidos durante meus estudos de Lógica de Programação, organizados por categoria.

## estruturas-de-dados

Exercícios sobre listas, tuplas, dicionários, sets, filas, pilhas, listas encadeadas, heap e hashing.

- estruturas.py: notas de estudo sobre listas, tuplas, dicionários e sets
- estudantes.py: cadastro de estudantes usando dicionários e sets
- filas.py: implementação de fila usando deque
- funcoes.py: funções, parâmetros padrão e escopo de variáveis
- hash.py: agrupamento de palavras por letra inicial usando dicionário
- heap.py: fila de prioridade com heapq
- lista-encadeada.py: implementação manual de lista encadeada
- pilhas.py: implementação de pilha usando deque

## fundamentos

Exercícios iniciais de lógica, condicionais e entrada e saída de dados.

- adivinhe-a-cor.py e adivinhe-o-numero.py: simulações de leitura de mente
- cracha-do-dev.py: gerador de crachá a partir de dados digitados
- historia-maluca.py e madlib.py: histórias geradas a partir de palavras do usuário
- love-scan.py e magica.py: pequenas brincadeiras interativas de terminal
- media.py e media-final.py: cálculo de média de notas
- notas.py e teste-condicional.py: exercícios de condicionais
- programa.py: primeiro programa, hello world
- sabio-python.py: menu interativo que explica conceitos de Python
- soma.py: soma de números com loop

## jogos

- caca-ao-tesouro.py: jogo de exploração em grade com mapa e tentativas limitadas
- hanoi.py: solução recursiva da Torre de Hanói
- jogo-adivinha.py: jogo de adivinhação que aprende novas perguntas com o jogador
- numero-secreto.py: jogo de adivinhar número com dicas de maior ou menor
- quiz.py: quiz interativo com pontuação

## manipulacao-de-texto

- textos.py: analisador de strings com contagem, transformações e fatiamento

## projetos

- assistente.py: chatbot simples de comandos por texto
- jogo-da-velha.py: jogo da velha com verificação de vitória em linhas, colunas e diagonais
- lista-de-tarefas.py: sistema de gerenciamento de tarefas via terminal
